# Vector Marketplace Companion privacy notice

Effective September 10, 2026.

Vector Marketplace Companion connects a Facebook Marketplace tab in Chrome to the Vector desktop app on your computer. It does not operate independently of the desktop app.

Before the extension reads Marketplace data, its popup explains the data flow and asks you to choose **Connect Marketplace**. You can decline by closing the popup, and you can disconnect at any time.

## Data used

When you connect the extension and run a workflow in Vector, the extension reads visible Marketplace listing details, listing photos, page controls and relevant conversation text. It sends these observations to the local desktop app using Chrome Native Messaging. The app uses them to perform the inventory, discovery, listing or conversation task you enabled.

The extension does not read browser cookies, saved passwords, passkeys, payment cards or browser history. Login and identity verification remain in Chrome. The extension does not run an analytics or advertising service and does not sell data.

## AI processing

Vector sends relevant task data, including listing information and conversation text when needed, to the AI provider you select through your installed Codex or Claude Code CLI. This is processing by that provider, not exclusively on-device AI. That provider's terms, privacy policy and retention settings apply. You can disconnect the extension or stop work in Vector.

## Local storage and deletion

The extension stores connection status locally in Chrome. Its working page observations and prepared photo are held in memory and cleared on disconnect. Vector stores inventory, selected listing details, workflow history and sales records locally, including local backups. Remove unwanted records in Vector and remove associated backup files to delete retained copies. Uninstalling only the extension does not delete the desktop app's database or backups.

## Permissions

Facebook host access and scripting allow the extension to read and operate the connected Marketplace tab. Native Messaging connects it to the installed Vector helper. Storage keeps the connection status. The extension contains its browser action code; it does not download or execute AI-generated JavaScript.

## Scope

The extension has no Vector cloud backend. Facebook and the chosen AI provider still process data involved in their respective services. Neither Google, Meta, OpenAI nor Anthropic sponsors or endorses Vector.

## Limited use

Vector uses Marketplace data only to provide the inventory, sourcing, listing, conversation, and pickup features the user enables. It does not use or transfer this data for personalized advertising, credit decisions, data brokerage, or unrelated purposes. No Vector employee or contributor receives access to a user's Marketplace data through a Vector service. A user may deliberately provide a specific record when requesting support, but Vector has no automatic support upload.
