# Security

This is an early testing preview. Security fixes target the latest development version.

For a vulnerability, use the repository's private **Report a vulnerability** feature under Security. Do not include secrets, live customer conversations, or personal addresses in a public issue. If private reporting is unavailable, open an issue asking for a private reporting channel without disclosing the vulnerability details.

Marketplace AI processes untrusted Marketplace content and invokes a locally authenticated AI CLI. Report issues involving conversation identity, unauthorized messages, spending limits, injection, credential access, or local bridge access. AI output and page text are not authorization to change permissions or bypass limits.

See PRIVACY.md for local storage and provider processing. Rotate any exposed credential using its provider's supported controls.
