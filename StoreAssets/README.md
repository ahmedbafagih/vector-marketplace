# Chrome Web Store assets

Run `python3 scripts/build-store-assets.py` after refreshing any `*-source.png` captures.

Upload:

- `store-icon-128.png` as the store icon.
- `small-promo-440x280.png` as the required small promotional image.
- `marquee-1400x560.png` as the optional marquee image.
- `screenshot-1-welcome-1280x800.png` through `screenshot-4-connect-1280x800.png` in numbered order.

All screenshots come from an isolated first-run Marketplace AI profile with synthetic setup values. They contain no private inventory, Facebook conversations, account details, or personal addresses. The city shown is a setup example.
