# Chrome Web Store assets

Run `python3 scripts/build-store-assets.py` after refreshing any `*-source.png` captures.

Upload:

- `store-icon-128.png` as the store icon.
- `small-promo-440x280.png` as the required small promotional image.
- `marquee-1400x560.png` as the optional marquee image.
- `screenshot-1-welcome-1280x800.png` through `screenshot-5-disclosure-1280x800.png` in numbered order.

All screenshots come from an isolated first-run Vector profile with synthetic setup values. They contain no user inventory, Facebook conversation, account, or location data.
